# Schriften in diesem Ordner

Alle Schriftdateien sind selbst gehostet. Es wird zur Laufzeit **kein** externer
Font-Dienst aufgerufen (kein Google Fonts, kein CDN) — bewusste Entscheidung wegen
des Abmahnrisikos bei Einbindung entfernter Font-Server.

| Familie | Schnitte | Lizenz | Bezug |
|---|---|---|---|
| Montserrat | 300, 400, 600, 700 | SIL Open Font License 1.1 | Fontsource |
| Playfair Display | 400 italic, 600 italic | SIL Open Font License 1.1 | Fontsource |
| Space Grotesk | 500, 700 | SIL Open Font License 1.1 | Fontsource (`@fontsource/space-grotesk`) |
| IBM Plex Mono | 400, 600 | SIL Open Font License 1.1 | Fontsource (`@fontsource/ibm-plex-mono`) |
| IBM Plex Sans Arabic | 400, 600, 700 | SIL Open Font License 1.1 | Fontsource (`@fontsource/ibm-plex-sans-arabic`) |

Die SIL OFL 1.1 erlaubt Weitergabe und Einbettung, auch kommerziell. Bedingungen:
Lizenztext mitliefern, Schriftnamen bei Modifikation ändern, Schriften nicht
einzeln verkaufen. Es wurden keine Dateien verändert.

IBM Plex Sans Arabic wird nur geladen, wenn die Seite auf Arabisch umgeschaltet
wird — Montserrat, Space Grotesk und IBM Plex Mono enthalten keine arabischen
Glyphen, ohne eigene Schrift bräche der Satz optisch aus dem Auftritt aus.
